ผมมีโปรเจคนึงที่จะทำให้เพื่อนในห้องมีชื่อว่า SE-ONE.SITE Project Development
TECH STACK ที่ใช้ก็จะมี React JSX + Emotion + TailwindCSS V4 + Supabase + Priority Hints + Google Analytics + Google Tag Manager + CloudFlare Pages + PWA + Custom Domain + Custom Notification + Custom Title + apple.com Design ใช้ Design เหมือนกับ Apple.com นะครับถ้าไม่มีลิขสิทธิ์ ประมาณนี้ ระบบนี้จะไม่มี MockData 100% ให้ต่อกับ Supabase เท่านั้น
โดยหน้าที่ผมจะสร้างมีดังนี้
1. Landing หน้าแรกที่เวลาเข้าเว็บแล้วจะเห็นเป็นอันดับแรก
2. Talents หน้า GitHub ของทุกคนในรุ่น SE RMUTL 69 Generation 4
3. About หน้าเกี่ยวกับว่าสร้างขึ้นมาทำอะไรเพื่ออะไรจุดประสงค์อะไรผู้พัฒนาคือใครเป็นใครบ้าง
4. Support หน้าติดต่อหาแอดมินโปรแกรมเมอร์และผู้ใช้งานที่อยู่ในดิสบางส่วน (หน้านี้ต้องต่อไปยัง Discord เท่านั้น)
5. sework/landing หน้าสรุปงานทั้งหมดตั้งแต่ปี 1 ถึงปีที่ 4 โดยแต่ละปีมี 3 เทอม และ 1 ปีมี 2 SEC / SEC1 เรียนปกติ 4 ปี SEC2 เทียบโอนเรียนประมาณ 3 ปีถึง 3 ปีครึ่ง เนื่องจากมีการเทียบโอนผลการเรียนมาแล้ว โชว์บางอย่างเท่านั้นอย่าโชว์เยอะ สิ่งที่โชว์ได้แน่ๆคือ สถานะระบบเป็นยังไงบ้าง แหล่งส่งงาน ตารางเรียน ประกาศ งานที่่ต้องส่ง
6. sework/login หน้าล็อกอินเข้าไปยังหลังบ้านที่สามารถจัดการได้ทั้งหมดของระบบ sework เท่านั้นโดยมี Role ดังนี้ admin(แอดมิน) manager(ผู้จัดการ) ceo(ผู้บริหารสิทธิ์สูงสุด) เมื่อใส่รหัสถูกให้ Redirect ไปยัง sework/console/dashboard เสมอและเมื่อเข้าสู่ระบบได้หน้า login ต้องเข้าไม่ได้จนกว่าจะกดออกจากระบบหรือระบบตัด Session ออกไปเอง
7. sework/forgot-password หน้าลืมรหัสผ่านของ admin manager ceo สามารถเปลี่ยนใหม่ได้โดยให้กรอกข้อมูลให้ถูกต้อง 100% ถ้าไม่ถูกก็ไม่สามารถเปลี่ยนได้ กันคนข้างนอกเข้าใช้งาน
8. sework/se-console/dashboard ภาพรวมของระบบ sework ต่างๆไม่ว่าจะเป็น ปีการศึกษานี้มีงานอยู่เท่าไร เทอมนี้เทอมที่เท่าไหร่ อยู่ SEC อะไร User ผู้ใช้งานทั้งหมดมีกี่ User ประวัติการกระทำภายในระบบย้อนหลัง 3 วัน 
9. sework/se-console/announcements จัดการประกาศข่าวสารภายในปีการศึกษา เทอม SEC หรือรวมเลย แจ้งเตือนผ่านดิสคอร์ด
10. sework/se-console/assignments หน้าสร้างงานโดยจะมีให้เลือก ปีการศึกษา เทอม และ SEC พอเลือกเสร็จให้เลือก รายวิชาต่อ ตามด้วยชื่องาน รายละเอียดงาน วันเวลาที่สั่งและกำหนดส่ง ไฟล์แนบประกอบการสั่งงาน(ถ้ามี) และสามารถดูได้ว่าสั่งงานอะไรไว้บ้างในปีการศึกษา เทอม และ SEC นั้นๆ Export ข้อมูลได้ แจ้งเตือนผ่านดิสคอร์ดด้วย
11. sework/se-console/schedules หน้าดูตารางเรียนภายในปีการศึกษา เทอม และ SEC ปัจจุบัน สามารถเพิ่มและลบได้ แจ้งเตือนผ่านดิสคอร์ดด้วย
12. sework/se-console/subjects หน้าจัดการรายวิชาภายในปีการศึกษา เทอม และ SEC นั้นๆ ไม่ว่าจะเป็นเพิ่มหรือลบ โดยให้ใส่ดังนี้ ปีการศึกษา เทอม SEC รหัสวิชา ชื่อรายวิชา ครูผู้สอน/ประจำรายวิชา แจ้งเตือนผ่านดิสคอร์ดด้วย
13. sework/se-console/sheet-data หน้าเอกสารสไลด์ใบงานรายสัปดาห์ภายในปีการศึกษา เทอม และ SEC ปัจจุบัน ปีการศึกษา เทอม SEC รายวิชา สัปดาห์ที่สอน ชื่อเอกสาร ประเภท(เอกสาร สไลด์ ลิ้งค์อื่นๆ) แนบไฟล์เอกสาร Export ข้อมูลได้ แจ้งเตือนผ่านดิสคอร์ดด้วย
14. sework/se-console/resource-center หน้าจัดการคลังเอกสารกลางภายในปีการศึกษา เทอม และ SEC ปัจจุบันที่ตัวเองอยู่เท่านั้นไม่สามารถโหลดของ ปีอื่น เทอมอื่น และ SEC อื่นได้ (ชื่อไฟล์ในเว็บต้องรองรับทั้งภาษาไทยและอังกฤษนะ) Export ข้อมูลได้ แจ้งเตือนผ่านดิสคอร์ดด้วย
15. sework/se-console/submission-links หน้าจัดการแหล่งส่งงานไม่ว่าจะเป็นลิ้งค์ Google Drive OneDrive หรืออื่นๆให้มารวมอยู่ที่นี่โดยถ้าจะเพิ่ม ปีของอะไร ปีการศึกษา เทอม และ SEC ชื่อแหล่งส่งงาน URL ปลายทาง แจ้งเตือนผ่านดิสคอร์ดด้วย
16. sework/se-console/submission-tracking หน้าติดตามสถานะการส่งงานเป็นรายบุคคลโดยให้แยกเป็นปีการศึกษา เทอม และ SEC แจ้งเตือนผ่านดิสคอร์ด เมื่อมีการกดส่งงานแบบกดปุ่ม Manual ไม่จำกัด Role นะไม่ว่า Role ไหนก็ต้องกดแค่สถานะควบคุมแตกต่างกันเฉยๆ Export ข้อมูลได้ แจ้งเตือนผ่านดิสคอร์ดด้วย
17. sework/se-console/leaderboard หน้าจัดอันดับยอดนักปั่นงาน Wall Of Frame (1 งาน = 300 แต้ม) แยกปี(ปี 1 2 3 4) เทอม และ SEC นะ แจ้งเตือนผ่านดิสคอร์ดด้วยเมื่อมีคนนำและมีคนตกอันดับ 
18. sework/se-console/users หน้าจัดการบัญชีผู้ใช้งานสามารถดูข้อมูลแก้ไขสิทธิ์บล็อกไม่ให้เข้าใช้งานรายบุคคลแจ้งเปลี่ยนรหัสผ่านด่วนโดยหน้านี้ที่จัดการได้จะมีแค่สิทธิ์ Manager กับ CEO เท่านั้น โดยถ้าจะสร้างเพิ่มบนเว็บแบบ Manual ให้กรอกข้อมูลดังนี้ ชื่อจริง นามสกุล ชื่อเล่น ระดับสิทธิ์(ตั้งได้ไม่เกิน Role ของตัวเอง) Email Password Confirm Password Facebook Instagram GitHub Account Tel. ปี(1 2 3 4) SEC(1 2) อัพโหลดรูปโปรไฟล์(ถ้ามี) แจ้งเตือนผ่านดิสคอร์ดด้วย
